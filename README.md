# E-Commerce-System
Spring Boot, PostgreSQL, Redis, RabbitMQ ve Docker kullanılan, kimlik doğrulama, ürün yönetimi, sepet, sipariş ve stok modüllerinden oluşan microservice tabanlı e-ticaret sistemi.

Bu proje; Spring Boot, PostgreSQL, Redis ve RabbitMQ kullanılarak tasarlanmış, tamamen microservices mimarisi üzerinde çalışan bir E-Commerce sistemidir.
Her servis bağımsız olarak çalışır, kendi veritabanına sahiptir ve mesajlaşma altyapısı üzerinden iletişim kurar.

Platform; kullanıcı kimlik doğrulama, ürün yönetimi, sepet işlemleri, sipariş oluşturma ve stok yönetimini kapsayan uçtan uca bir e-ticaret altyapısı sağlar.
